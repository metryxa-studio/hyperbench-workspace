# Hyperbench Workspace

Local, open-source hardware context workspace. No code indexer, hosted backend, analytics, model provider credentials, or bundled agent harness. Agents connect through MCP and retain their own permissions and model configuration.

Keep data local. Bind browser services to loopback, authenticate API access, reject foreign origins and unsafe filesystem paths. Agent edits are drafts; only explicit user actions save them. Preserve optimistic concurrency across UI and MCP processes. Never publish personal repositories, documents, credentials, private source history, or generated user state.

Use TypeScript, React, SQLite, and the official MCP SDK. Keep module ownership clear during parallel work. Test observable behavior, including filesystem boundaries and concurrent saves. Root owns Git commits and publication. Public release is authorized by the user for this new repository only.
